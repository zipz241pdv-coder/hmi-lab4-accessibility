# Покращення доступності вебсторінок (WCAG 2.1) — ACME Fashion House

Навчальний проєкт із дисципліни **«Людино-машинний інтерфейс»** (Тема № 4: «Покращення доступності вебсторінок»).
Метою роботи є практичне застосування стандартів вебдоступності **WCAG 2.1 (рівні A та AA)** для семантичної структуризації контенту, налаштування клавіатурної навігації, коректної взаємодії з екранними зчитувачами та підвищення контрастності інтерфейсу.

---

## 📁 Структура проєкту

```text
├── main.html              # Головна сторінка інтернет-магазину (оптимізована для доступності)
├── form.html              # Сторінка реєстрації та вибору параметрів доставки (доступна вебформа)
├── assets/
│   ├── css/
│   │   ├── site.css       # Користувацькі стилі сторінок
│   │   └── theme.css      # Базові стилі теми оформлення
│   ├── fonts/             # Іконочний шрифт Feather
│   └── img/               # Зображення товарів, логотипи та іконки платіжних систем
└── README.md              # Опис проєкту та виконаних покращень доступності
```

## ✅ Виконані покращення доступності

### 1. Головна сторінка (`main.html`)
* **Релевантний заголовок та мова документа:** встановлено змістовний `<title>` (`Home | ACME Fashion House`) та атрибут британської англійської мови `lang="en-GB"` у тегу `<html>` для коректної вимови синтезаторами мовлення.
* **Пропуск повторюваного контенту (Skip Link):** додано приховане посилання `Skip to main content`, яке з'являється при фокусуванні з клавіатури (`Tab`) та переводить фокус безпосередньо до `<main id="main-content">`.
* **Логічна ієрархія заголовків:** замінено несемантичні контейнери на послідовну структуру заголовків `<h1>` → `<h2>` → `<h3>` без пропуску рівнів.
* **HTML5-орієнтири (Landmarks):** розмічено ключові зони сторінки за допомогою `<header>`, `<nav>`, `<main>`, `<section>`, `<article>` та `<footer>`.
* **Природний порядок фокуса:** видалено штучні позитивні атрибути `tabindex="1".."17"` із посилань у нижньому колонтитулі.
* **Контрастність кольорів:** скориговано кольори тексту та кнопок (`.text-gray-400`, `.text-gray-500`, `.text-muted`, `.text-primary`, `.footer .text-gray-300`, `.btn-gray-500`), забезпечивши співвідношення контрасту не нижче $4.5:1$.
* **Альтернативний текст зображень:** додано змістовні описи `alt` для інформативних зображень товарів, `alt=""` для декоративних карток і `aria-hidden="true"` для іконочних шрифтів.
* **Семантичні елементи та контекст посилань:** оформлено відгуки покупців через `<figure>`, `<blockquote>` та `<figcaption>`, рейтинги зірочками — через `role="img"` та `aria-label`, додано уточнювальні `aria-label` для кнопок-іконок та згруповано навігаційні посилання у футері в списки `<ul>`.

### 2. Вебформа (`form.html`)
* **Зв'язування міток із полями:** прив'язано всі теги `<label>` до відповідних елементів керування через `for` та `id`, обгорнуто форму в семантичний тег `<form>`, додано `type="email"` та атрибути `autocomplete`.
* **Позначення обов'язкових полів:** програмно (`required`, `aria-required="true"`) та візуально (`*` із поясненням) виділено всі обов'язкові поля, окрім необов'язкових *«Signup to our newsletter»* та *«Shipping option preferences»*.
* **Логічне групування елементів:** об'єднано перемикачі варіантів доставки у `<fieldset>` із заголовком `<legend>Shipping option preferences</legend>`.

## 🧪 Тестування та валідація

Перевірку доступності виконано комбінованим підходом:
1. **Автоматичний аудит:** розширення **axe DevTools** та **WAVE** (усунено критичні помилки та порушення контрасту за стандартом WCAG 2.1 AA).
2. **Клавіатурна навігація:** перевірено послідовний обхід усіх інтерактивних елементів за допомогою `Tab` / `Shift + Tab`, видимість індикатора фокуса та активацію елементів (`Enter` / `Space`).
3. **Тестування екранним зчитувачем:** перевірено озвучування заголовків, орієнтирів, зображень, станів і підказок форми у **NVDA**.
